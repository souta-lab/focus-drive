# FOCUS DRIVE — 実装レビュー (2026-10-18)

対象: /home/s0u7a/projects/focus-drive
範囲: コアアルゴリズム、入出力、3D描画、進行、テスト、プレイ難易度。原作との実機同等性評価は未実施。

## 結論
垂直スライスの完成度と検証可能性は高い。最大の問題は初期難易度が低く、適応が緩慢で、走行イベントの成功が主たるNAV指標に含まれないこと。3D表現に対してゲームとしての緊張感が不足していた。

## 修正済み
- **OTC専用 High Challenge（既定ON）**：高成績時に最大 ROAD +6 / SIGN +3、5秒・7.5秒の最短再調整。精度低下時は段階的に引き下げ。
- **走行判定**：High Challengeでは ROAD レベル上昇に合わせて半幅3.2m未満へ縮小（下限1.75m）。標準/Classicでは3.2m。
- **イベント**：High Challengeでは平均出現間隔76m（標準115m）、Power Zone・Gateを細く、障害物を広く。Guideの最近の成績要件も引き上げ。
- **運転の公平性**：最高速度315km/h付近でコースの最大傾斜に対して横速度4.5m/sが足りなかったため、High Challenge高レベルで操舵権限を補正。
- **描画整合性**：roadTangentが数式上の微分より約1.67倍大きい問題を修正。
- **マウス**：pointerdownの記録元がtouchになっていた問題を修正。
- **検証**：新しい unit テストでHigh Challengeの上下適応、道路幅、イベント生成、接線、操作限界を固定。Classicのレベル規則・インターバルは変更せず。

## 残る優先課題
1. **NAV Accuracyは道路内滞在割合のみ**。Power Zone/Gate/Obstacleの達成は別イベントとして記録されるが、表示NAV Accuracyには反映されない。UIに EVENT 成功率を併記し、ゲーム報酬・Guide条件をさらに連携することを推奨。研究比較用の道路内精度は独立保持する。 → **追記で対応済み（Drive Score / EVENT表示 / コイン連携）**
2. **World 1のGo/No-Goは色違いの円3色のみ**。低難易度に感じる人がいる。公開World設計を変えるより、別枠で上級者向けの刺激課題を用意する方がよい。
3. **詳細なGLB車両は存在するが初期車両は手続き生成のF-01**。精密なCC BY車両を売りにするなら選択導線の改善と初期ガレージ体験の磨き込みが必要。
4. **導入時のBaselineは60秒運転→60秒標識→60秒同時課題**。初回の最初の2分は二重課題ではない。すぐ高負荷を体験できる独立練習（進行非加算）を用意するとよい。
5. **WebGLバンドルは約2.1MB**（gzip約560KB）。アセット負荷・低スペックへの最適化は継続課題。
6. **git未初期化**。検証済みの節目でリポジトリ化すると変更の巻き戻しが容易。
7. 高負荷版の手動プレイテスト（熟練者と初見）、FPS安定、スマホ/Firefox/Safariは未検証。通過判定の統計的公平性も別途測定が必要。

## 追記：レビュー後の実装（2026-10-18 23:xx）

優先課題1（NAVスコアとイベントの分離）と「Power Zone・障害物を攻略に直結させる」に対応。

- **イベントの帰結**: Power Zone +24%/2.8s、Gate +10%/1.5s、Obstacle回避 +8%/1.2s、Obstacle接触 -34%/2.4s＋横2.6m/sの衝撃。ペースは8%/stepで滑らかに遷移。
- **Drive Score**: `0.55×道路内 + 0.45×EVENT成功率`。HUDの`NAV`、結果画面、コイン、履歴表示に使用。`CLEAN LINE`（8連続成功）を追加。
- **研究指標は不変**: `navigation.accuracy`、Classic staircase、OTCの適応証拠、Navigation80、multitask costは従来どおり道路内割合のみ。Drive Scoreは別フィールド。
- **UI**: HUDに`EVENT`、結果画面に`DRIVE SCORE`と`道路% · EVENT n/m`、InsightsにEVENT SUCCESSカード、詳細に内訳を追加。
- **検証**: 第二監査後の最終コードでユニット82件、ブラウザE2E 8件、本番ビルド成功。新規テスト4件（効果表、Drive Score配合、Power Zone加速、Obstacle減速）。180秒実走行: 平均59.8FPS、イベント53/53、Drive Score 100、品質GOOD。実ブラウザで `paceFactor` 1.10→1.24（加速）と0.83→0.69（接触減速）を確認。詳細は [SECOND_AUDIT_2026-10-18.md](SECOND_AUDIT_2026-10-18.md)。
