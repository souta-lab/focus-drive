# 走行イベントとDrive Score（2026-10-18 追加）

レビューで指摘された「Power Zone・Gate・Obstacleが飾りで、NAVスコアに反映されない」問題への実装です。**ゲーム用の追加要素**であり、研究比較用の計測値やClassicのstaircaseは変更していません。

## 1. イベントが運転に与える影響

イベント通過時に、難易度レベルとは別の**一時的なペース倍率**と**横方向のインパルス**が決まります。**Classicモードではイベント自体を生成せず**、固定速度・道路のみの判定を維持します（第二監査で分離）。固定step内で決定的に計算され、速度は滑らかに目標値へ寄ります（毎step 8%）。倍率はミッションの生ログ（`NavigationEvent.success`）と合わせて再現できます。

| イベント | 結果 | 速度ボーナス | その他 |
|---|---|---|---|
| Power Zone | 通過 | **+4.5%**（持続） | 最も大きな上積み |
| Gate | くぐる | +2.0%（持続） | 小さな上積み |
| Obstacle | 回避 | +1.2%（持続） | クリーンライン |
| Obstacle | 接触 | **-6.0%** ＋ 0.9倍の一時減速（0.7秒） | 横方向へ 1.6 m/s |
| Gate / Power Zone | 失敗 | ±0 | 減速しない。EVENT成功率だけ下がる |

**速度は上下に揺れず、積み上がる。** 以前は通過ごとに +24% → 元に戻る、衝突で -34% という振れ幅だったため「早くなったり遅くなったりしてうざい」となっていた。現在はクリアした分がそのまま残り（上限 +22%）、衝突した時だけ少し失う。滑らかに遷移するので速度が飛ばない。

- ペース倍率は `MissionSnapshot.paceFactor` と `forwardSpeed` に反映され、HUDの `SURGE` / `RECOVER` 表示とカメラFOV（+最大7°）にも出ます。
- 設定「イベントで速度が変わる」でOFFにすると常に一定速度になります（既定ON）。
- 操舵権限は実速度に応じて計算するため、加速中も道路の最大曲率を追えます。
- 接触時のインパルスは`x`を直接動かさず`vx`に加えるので、固定stepの再現性を保ちます。

## 2. Drive Score（ゲーム用の複合表示）

```
Drive Score = 0.55 × 道路内滞在割合 + 0.45 × 通過イベント成功率
```

- イベントがまだ1つも通過していない場合は道路内割合のみ。両方なければ `null`。
- HUDの `NAV` はDrive Score、`EVENT` はイベント成功率を表示します。
- 結果画面は `DRIVE SCORE` を主表示にし、`道路〇% · EVENT n/m` を併記します。
- コインのNavigation分は `round(20 × Drive Score) + 成功イベント×2`。イベントを無視した走行はコインが伸びません。
- `CLEAN LINE` の実績（8イベント連続成功）を追加。失敗で連続記録はリセットされます。
- Guideの自動ロック条件は従来どおり**直近の**走行精度とイベント成功率を別々に要求します。

## 3. 研究指標との分離（重要）

| 用途 | 値 | 変更 |
|---|---|---|
| 研究比較・Classic staircase・OTC適応 | `summary.navigation.accuracy`（道路内の有効時間割合） | **変更なし** |
| Navigation80閾値・multitask cost | 上記の`accuracy` | **変更なし** |
| ゲーム表示・コイン・結果画面 | `navigation.driveScore` | 新規追加 |
| 生ログ | `NavigationEvent.success`, `MissionRecord.navigationSamples` | 既存項目のみ |

Drive Scoreは表示・報酬用です。能力推定、Classicのレベル更新、OTCの後験平均には使っていません。したがって「Drive Scoreが高い＝能力が高い」という主張はできません。

## 4. 高負荷チャレンジとの関係

`settings.challengeMode`（OTCのみ、既定ON）では、イベント間隔が約62–90m、評価幅が最大1.75mまで狭くなります。イベントのペース効果はチャレンジの有無にかかわらず同じです。Classicではチャレンジモード自体が無効化されます。

## 4b. 色の意味づけ（2026-10-19 修正）

以前は進入地点に**黄色い矢印（チェブロン）**を描いていましたが、レーンマークに見えてしまい「黄色のへんな線のせいでわけわからん」という指摘を受けました。現在は色で意味を固定しています。

| 色 | 意味 | 対象 |
|---|---|---|
| **ライム／緑** | 通ってよい・踏んでよい | Gate（アーチ）、Power Zone（路面の帯＋前向き矢印）、Guideリング |
| **赤／白のハザード縞** | 触れない | Obstacle（本体＋路面の縁石ブロック） |
| 橙 | 危険の警告灯のみ | Obstacle の両脇ランプ |

黄色い矢印は削除しました。また、**左から右へ流れる演出**（Gate通過時のスイープ、加速時の横縞）も画面を横切る線として紛らわしいため削除し、放射状の速度線だけを残しています。

## 5. 検証

- ユニット: 効果表の境界、Drive Scoreの配合と研究指標の不変、Power Zone通過後の実速度上昇、Obstacle接触後の減速・イベント成功率低下（`tests/unit/event-mechanics.test.ts`）。
- ブラウザ: HUDの `EVENT` 表示、結果画面の `DRIVE SCORE` 表示（`tests/e2e/app.spec.ts`）。
- 未検証: 人間の実プレイによる「面白さ」の評価、イベント密度とペース効果の統計的なバランス調整。数値はゲーム用の初期値であり、公開研究の値ではありません。
