# エンジン音を実録サンプルに置き換えた記録 (2026-10-19)

要望「音が変。エンジン音が。フリーのリアルデータ使えんの。回転数に対応する」への対応。

## 結論

- **合成音（オシレーターのドローン）を廃止**し、**実録のエンジン音4レイヤー**に置き換えた。
- 回転数（RPM）に応じて**レイヤーをクロスフェードし、再生速度（playbackRate）で音程を合わせる**。ATギアのシフトアップで回転数が落ちるため、**ギアチェンジが音で分かる**。
- 素材は **CC BY 4.0**（表示のみ・継承なし）。出典と改変内容を CREDITS とマニフェストに記録。

## 作り方（再現可能）

```bash
./scripts/fetch-engine-source.sh /tmp/engine/gto.ogg   # CC BY 4.0 音源を取得（リポジトリには入れない）
python3 scripts/build-engine-audio.py /tmp/engine/gto.ogg public/audio
```

`scripts/build-engine-audio.py` がやること:

1. モノラル44.1kHzで読み込み、**ファイル全体**に highpass 55Hz とコンプレッサを適用。→ ループを切ってからフィルタを掛けると、ループ端だけフィルタ状態が違ってプチノイズになるため順序が重要。
2. 自己相関で**エンジンの点火周期**を推定し、`t=56.85 / 24.00 / 42.60 / 42.15` 秒から**定常区間を4つ**抽出。点火周波数は 115 / 154 / 302 / 596 Hz とほぼ等間隔。
3. ループ長を**点火周期の整数倍**にスナップ。開始サンプルを「ループ終端の直後の値」に置き換える形で**周期長ぶんのクロスフェード**を掛けるため、巻き戻し点が連続になる。
4. ラウドネスを揃えて 16bit モノラル WAV で書き出し、`engine-layers.json`（ファイル名と基準RPM）を生成。

**MP3/AACではなくWAV**にしているのは、MP3のエンコーダ遅延（先頭に無音が入る）がループ接合を壊すため。4本合わせて約389KB。

### 採用した4区間

| ファイル | 点火周波数 | 基準RPM | 用途 |
|---|---|---|---|
| engine-1.wav | 115 Hz | 1154 | アイドル〜低速 |
| engine-2.wav | 154 Hz | 1542 | 低速〜中速 |
| engine-3.wav | 302 Hz | 3021 | 中速〜高速 |
| engine-4.wav | 596 Hz | 5959 | 高速〜レッドライン |

## 再生側

`src/ui/input.ts` の `DriveAudio`。

- `update(speed, on, lateral, rpm)` が毎フレーム呼ばれる。
- RPMを挟む2レイヤーを選び、**対数空間でblend**してクロスフェード。
- 各レイヤーの `playbackRate = rpm / 基準RPM`。これにより**2つのレイヤーの実効ピッチが一致**する（下の検証を参照）。
- RPMでローパスも開く（`1100 + rpm×0.6` Hz）。
- 風切り音（速度）とタイヤ音（横速度）は従来どおり合成ノイズ。

RPMは `src/main.ts` のATモデルから算出：`rpm = 1250 + (ギア帯内の進行度) × (8200 - 1250)`。8速ATなのでシフトアップごとに回転数が落ち、そのまま音に出る。

## 検証

```bash
pnpm verify:audio
```

ヘッドレス環境のため**音を聴くことはできない**。代わりに音声グラフの状態を数値で検証している。

- AudioContext `running`、レイヤー4本、`/audio/engine-layers.json` と4つのWAVがすべて 200 で取得成功。
- **実際に聞こえている上位2レイヤーの実効ピッチ（rate × 基準RPM）が1〜2rpm以内で一致**。例: 3532/3534、2134/2133、4493/4495、5976/5977 rpm。
- ギアごとの回転数を確認：3速 2619→4493→5976、5速 2134→2384→2912 rpm と**シフトアップで回転数が落ちる**。
- ページエラー0、失敗リクエスト0。
- 生データ: `docs/verification/audio-verification.json`。

### 正直な限界

- **この環境では聴感を確認できない。** 検証したのはグラフの状態とピッチ整合であり、「良い音かどうか」は未評価。実際に聴いて判断してほしい。
- 素材はF1ではなく**250 GTO のV12**。近いが同一ではない。
- 4本の録音は**別々の瞬間**のもので、連続したRPMスイープではない。クロスフェード点でわずかな音色差が残る可能性がある。
- ループ長1.1秒のため、**1秒周期のわずかな周期性**が知覚される可能性がある。
- 実機の聴感テスト、ヘッドホン/スピーカー差、モバイルSafari の WAV デコードは未検証。
