# 走行体験：ガイド・ガードレール・音・コース（2026-10-19）

プレイヤーからの「ガイドが気持ち悪い」「柵の外を走れる」「コースが単調」「音とエフェクトがない」「最初から二重課題でいい」というフィードバックへの対応です。いずれも**ゲーム表現**の変更で、研究比較用の判定・計測値は変えていません。

## ガイド（自動ロック）

以前は浮遊カプセル＋球＋斜めのテザーがあり、生物のように見えました。現在は**路面に描かれた発光リング**です。

- 進行方向 20m の路面に、淡いライムのリング・四方向の目盛り・細い光柱を表示。
- ロック進行はリングに沿って円弧が伸びる表現。車とリングを結ぶテザーはありません。
- ガイドの位置（`guide.offset`）は従来どおり左右の狙い位置で、リングも同じ位置に描かれます。
- ロック条件・タイミング・報酬は変更していません。

## ガードレール

- OTC/Arcadeでは、車の横位置を道路中心から **最大 3.4m**（道路半幅4.2m − 車半幅0.8m）に拘束。Classicは研究互換のため拘束しません。
- はみ出そうになると位置をクランプし、横速度を減衰。`GUARDRAIL` のフィードバックと効果音、画面の茶色いビネットを出します（900msクールダウン）。
- **評価幅（1.75〜3.2m）はこれより狭い**ため、ガードレールは「走行を止める壁」であり、スコアを甘くするものではありません。道路中心関数・イベント距離・研究指標は不変です。

## 音

- 効果音はすべて**WebAudioで合成**。外部音源なし。
- 常時：エンジン（速度で音程・フィルターが変化）、風切り音（速度）、タイヤ音（横速度）。
- 一回：Target HIT / MISS / FALSE_ALARM、Power Zone、Gate、Obstacle接触、ガードレール、Guide捕獲。
- 初期設定は**ON**。設定の「サウンド」でOFFにできます。AudioContextは開始クリック後に生成します。
- 音は任意で、失敗してもゲーム進行や計測には影響しません。

## 画面エフェクト

- HIT：淡い発光、MISS：周辺の暗いビネット、Power Zone：緑のフラッシュ、Gate：横方向のスイープ、Obstacle：赤いビネット＋小さな画面揺れ、Guardrail：茶色のビネット。
- 加速中は左右に薄いスピードライン。
- 設定「演出を控えめに」またはOSの`prefers-reduced-motion`でアニメーションを停止します。

## コースの変化

評価用の中心線・道路幅・イベント距離は変えず、景観だけを追加しています。

| 要素 | 間隔 | 内容 |
|---|---|---|
| 距離標 | 100m | 右肩上の白いボードと支柱 |
| トラックサイドバナー | 120m | ライム／生成りの大型パネル（左右交互） |
| チェッカー帯 | 500m | 路面を横切る白／濃色の帯 |
| ゲート看板 | 360m | 両側支柱＋ヘッダー＋右側バナー |
| 風車 | 640m | 左側の丘（World 1/2） |
| 路面セクター | 180m | 再舗装風の色帯 |
| ショルダーカーブ | 6m | 明暗交互の縁石ブロック |

## 開始フロー

- **初回から二重課題**：`nextMission` は最初から `taskMode: 'DUAL'` を返し、Baselineも180秒の二重課題として進行に数えます。
- 単独課題の分割Baseline（60秒×3）は、`MissionEngine`に`taskMode`を明示しない研究用構成として残しています。Classic較正も従来どおりです。
- 研究のmultitask costを出すには、単独課題のClassic較正または研究用セッションが必要です。

## 未対応・限界

- 音は合成音で、実車のエンジン録音・音楽・3D空間音響ではありません。
- コースは依然として同じ中心線関数の無限道路で、トンネル・分岐・高低差は未実装です。
- ガイドの見た目・音・エフェクトは主観評価を受けておらず、人間のプレイテストが必要です。
